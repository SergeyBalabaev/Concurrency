Гонка потоков: блокировки

Код из программ семинара: deadlock.c, philo.c, list.c, lru.c. Каждый ход — одна строка одного потока. Подберите порядок ходов, при котором код сломается.

    1 2 3 шаг потока T0 / T1 / T2
    Backspace отменить шаг
    R заново
    Одна строка — один неделимый шаг. Все записи сразу видны другим потокам. Шаг потока, который ждёт мьютекс, ничего не меняет. «—» у мьютекса значит «свободен».
