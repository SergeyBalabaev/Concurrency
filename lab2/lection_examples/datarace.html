Гонка потоков

Каждый ход — одна строка одного потока. Подберите такой порядок ходов, чтобы код синхронизации перестал работать.

    1 2 шаг потока 0 / 1
    Backspace отменить шаг
    R заново
    Одна строка — один неделимый шаг. Все записи сразу видны другому потоку.
